# Forms Bundle

BladewindUI forms bundle — installs all form components (Input, Select, Checkbox, Radio, Toggle, Datepicker, Timepicker, Colorpicker, Filepicker, Slider, Checkcards, Textarea, Number, Code).

## Installation

```bash
composer require bladewindui/forms
```

### Included packages

| Package | Component |
|---|---|
| `bladewindui/input` | Input |
| `bladewindui/textarea` | Textarea |
| `bladewindui/select` | Select |
| `bladewindui/checkbox` | Checkbox |
| `bladewindui/radio` | Radio Button |
| `bladewindui/toggle` | Toggle / Switch |
| `bladewindui/datepicker` | Datepicker |
| `bladewindui/timepicker` | Timepicker |
| `bladewindui/colorpicker` | Color Picker |
| `bladewindui/filepicker` | File Picker |
| `bladewindui/slider` | Slider |
| `bladewindui/checkcards` | Check Cards |
| `bladewindui/number` | Number Stepper |
| `bladewindui/code` | Verification / OTP Code Input |

You can also install the full BladewindUI library in one go:

```bash
composer require bladewindui/ui
```
