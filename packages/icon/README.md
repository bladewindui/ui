# Icon

BladewindUI Icon component — Heroicons-powered SVG icons.

> **Note:** `bladewindui/icon` is a shared dependency — it is pulled in automatically when you install any BladewindUI component. You do not normally need to require it directly.

## Installation

```bash
composer require bladewindui/icon
```

## Documentation

Full documentation, live demos, and all available attributes are at **[bladewindui.com](https://bladewindui.com)**.
